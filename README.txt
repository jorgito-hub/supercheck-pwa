SuperCheck - Paquete PWA listo para PWABuilder
Contenido del ZIP:
- index.html (versión preparada para PWA)
- SuperCheck.html (mismo archivo)
- manifest.json
- sw.js (service worker básico para caching)
- icons/icon-192.png
- icons/icon-512.png

Instrucciones rápidas:
1) Ve a https://www.pwabuilder.com
2) Selecciona 'Package my PWA' y sube este archivo ZIP.
3) PWABuilder revisará el manifest y service worker y te ayudará a crear el APK/Android package.
4) Para probar localmente, sirve el contenido mediante un servidor HTTPS (o usa localhost) y asegúrate de que manifest.json y sw.js se sirvan correctamente.
